# 拾光影棚 · Photo Magic

上传一张生活照，一键生成 **证件照 / 商务照 / 写真 / 表情包** 四套精修成品。

## 当前版本（演示 MVP）

- 纯前端 Canvas 处理，所有图像处理都在浏览器本地完成，不上传服务器
- 免费预览图带「预览」水印
- 「解锁高清无水印 9.9 元」→ 微信收款码 + 「我已支付」按钮（临时支付通道）
- 解锁后交付：
  - 证件照 / 商务照 → 单张 + A4 排版（25×35mm，300dpi，2×4 共 8 张，可直接送印）
  - 写真 → 4 张拼版
  - 表情包 → 9 宫格

## 尚未接入

- 自动支付接口（当前靠手动点「我已支付」）
